# Medical Cost Predictor

**AI/ML Build Week – Day 7 Assignment**

A complete machine learning workflow that classifies whether a person's medical insurance charges are **high cost** (above median) or **low cost**.

---

## Project Structure

```
medical-cost-predictor/
├── insurance.csv                   # Dataset
├── medical_cost_classifier.ipynb  # Full ML workflow (EDA → train → evaluate → save)
├── app.py                          # Gradio web app for deployment
├── best_model.pkl                  # Saved best model (generated by notebook)
├── requirements.txt                # Python dependencies
└── README.md
```

---

## What the Notebook Covers

| Step | Description |
|------|-------------|
| 1 | Load & explore data (info, describe, missing values) |
| 2 | Visualisations: charge distribution, smoker analysis, BMI scatter |
| 3 | Preprocessing: binary encoding, one-hot encoding, target creation |
| 4 | Train **Logistic Regression**, **Decision Tree (default)**, **Decision Tree (pruned)** |
| 5 | Evaluate with Accuracy, Precision, Recall, F1 + Confusion Matrix heatmaps |
| 6 | Model comparison — best selected by **recall** (catches more high-cost patients) |
| 7 | Save best model with `joblib` |

---

## Running the Project

### 1 · Install dependencies
```bash
pip install -r requirements.txt
```

### 2 · Run the notebook
Open `medical_cost_classifier.ipynb` in Jupyter and run all cells.  
This will generate `best_model.pkl`.

### 3 · Launch the web app
```bash
python app.py
```
Open the printed local URL in your browser.

---

## Web App Features

- Input sliders/dropdowns for: Age, Sex, BMI, Children, Smoker, Region
- Instant **High Cost / Low Cost** prediction with probability
- **Prediction history** table (bonus feature)

---

## Dataset

[UCI Medical Insurance Dataset](https://www.kaggle.com/datasets/mirichoi0218/insurance)  
1338 rows · 7 features: `age`, `sex`, `bmi`, `children`, `smoker`, `region`, `charges`

---

## Key Finding

The **smoker** feature is by far the strongest predictor of high medical costs.  
Smokers are ~4× more likely to fall in the high-cost category.
